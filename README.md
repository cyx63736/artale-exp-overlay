# Artale 經驗收益計算器

在遊戲上即時算經驗收益效率：EXP、藥水花費、楓幣收益、升級預估時間

## 系統需求
- Windows 10 / 11（64 位元）
- 執行時記憶體約 150 MB

## 使用
1. Releases 下載 zip，解壓後開 ExpOverlay.exe
2. 按 ⚙ 填藥水名稱和單價，框選 EXP、快捷欄藥水、背包（請打開背包切到消耗欄框選）
3. 按 ▶ 開始

Ctrl+F10 開始/暫停　Ctrl+F11 手動記錄　Ctrl+F12 顯示/隱藏

建議可以視窗化長按win+↑ 開著背包不擋視線
